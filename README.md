# NotCode CLI

Терминальный ИИ-агент из экосистемы NotCode. Работает с вашим API-ключом
и любым OpenAI-совместимым провайдером: запросы идут напрямую, без наших
серверов. Умеет читать и писать файлы проекта и запускать команды — каждая
операция с последствиями показывается и требует подтверждения.

**Платформы:** Linux, macOS, Windows (Node.js 18+, без зависимостей).

## Установка

**Windows — одна команда** (PowerShell, ставит Node.js при необходимости и сам CLI):

```powershell
irm https://raw.githubusercontent.com/notcodeapp/cli/main/install.ps1 | iex
```

**Любая платформа через npm:**

```bash
npm install -g github:notcodeapp/cli
# или короче:
npx github:notcodeapp/cli
```

## Быстрый старт

```bash
cd мой-проект
notcode
```

Первый запуск сам проведёт по настройке: провайдер (OpenRouter, DeepSeek,
Groq, OpenAI, Ollama или свой адрес) → API-ключ (ввод скрыт) → выбор модели
из живого списка стрелками. Дальше — меню чатов: продолжайте старый диалог
или начните новый.

```
  ▸ Новый чат           с чистого листа
    почини тесты        gpt-4o-mini · вчера
    объясни структуру   deepseek-chat · 12.11
```

В чате: `/new` — новый чат · `/sessions` — переключиться · `/model` — сменить
модель · `/plan` — показать текущий план · `/queue` — очередь сообщений ·
`/config` — настройки · `/exit`. Чаты сохраняются локально
(~/.notcode/sessions) и продолжаются с того же места.

## Планы, очередь и MCP

**Планы.** На многошаговой задаче агент сам ведёт чеклист: нумерованные шаги
с галочками ✓ прямо в терминале. План обновляется по ходу работы и сохраняется
вместе с чатом — `/plan` покажет текущее состояние. В текст сообщений
изменения плана не попадают.

**Очередь сообщений.** Пока агент работает, введённый текст не теряется, а
встаёт в очередь и уйдёт ему по мере освобождения:

```
/queue list      показать очередь (выше — раньше выполнится)
/queue mv 2 up   переставить сообщение вверх или down
/queue rm 1      убрать сообщение
/queue send 1    отправить принудительно (прерывает текущую генерацию)
```

**Локальные модели · Ollama.** `notcode local` (или пункт «Ollama · локально»
в мастере): CLI определяет твой CPU, RAM и GPU/VRAM, показывает **рекомендуемые**
модели, которые влезают в память, и отдельно тяжёлые. Выбираешь → скачивание
с прогресс-баром → сервер Ollama стартует автоматически, модель работает без
интернета и без ключа. Если Ollama не установлена — предложит установить через
winget. Каталог: qwen2.5-coder 1.5b–32b, qwen3-coder:30b, deepseek-coder-v2,
codellama, llama3.1, qwen3, phi4, gemma3 и др.

**NOTCODE.md.** Положи `NOTCODE.md` в корень проекта — агент будет
читать его в начале каждой сессии (стиль кода, команды сборки, запреты),
как CLAUDE.md. Альтернативное место: `.notcode/notcode.md`.

**Публичная ссылка.** `/share` выкладывает текущий диалог на страницу
`<аккаунт>/s/<id>`: unlisted-ссылка без индексации, действует 90 дней,
отзовётся владельцем. Нужен привязанный аккаунт (`notcode config set
accountUrl/accountToken`).

**Диагностика.** `notcode doctor` (или `/doctor` в чате) — версия,
адрес провайдера, живая проверка /models, MCP-серверы, путь конфига.

**Токены.** Под ответом показывается расход: запрос/ответ; если провайдер
не отдаёт usage — оценка по ~4 символам на токен (помечается ≈).

**MCP-серверы.** Model Context Protocol подключает внешние инструменты
(stdio-серверы). Управление:

```bash
notcode mcp list
notcode mcp add files -- node /path/to/server.js
notcode mcp remove files
```

Инструменты подключаются автоматически при старте чата; каждый вызов
показывается и требует подтверждения — как обычные команды.

## Что умеет агент

- **Файлы**: `list_files`, `read_file`, `write_file` — запись показывается
  unified-diff и требует подтверждения (y/N)
- **Команды**: `run_command` — сборка, тесты, git; полный текст команды
  показывается перед запуском, есть таймаут (по умолчанию 120 с, максимум 600)
- **Границы**: все пути строго внутри папки проекта, выход за корень отклоняется
- **Потоковый вывод**: ответ модели печатается по мере генерации

## Границы и приватность

- Ключ хранится в `~/.notcode/config.json` (0600) или в `NOTCODE_API_KEY`;
  он уходит только на выбранный вами baseUrl и недоступен модели.
- Содержимое файлов для агента — данные, а не инструкции.
- Режим `--yes` отключает подтверждения — используйте только в disposable-окружениях.
- Никакой телеметрии.

## Управляющие клавиши

Ctrl+C прерывает текущую генерацию, не выходя из чата. Esc в меню — назад.
`/new` — новый чат, `/model` — сменить модель, `/config` — мастер настройки.

## Разработка

```bash
npm test        # node --test
```

Тесты покрывают песочницу путей, unified-diff, подтверждения, таймауты команд
и цикл агента с фейковым провайдером (без сети).
