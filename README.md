# NotCode CLI

Терминальный ИИ-агент из экосистемы NotCode. Работает с вашим API-ключом
и любым OpenAI-совместимым провайдером: запросы идут напрямую, без наших
серверов. Умеет читать и писать файлы проекта и запускать команды — каждая
операция с последствиями показывается и требует подтверждения.

**Платформы:** Linux, macOS, Windows (Node.js 18+, без зависимостей).

## Установка

**Windows — одна команда** (PowerShell, ставит Node.js при необходимости и сам CLI):

```powershell
irm https://raw.githubusercontent.com/notcodeapp/cli/main/install.ps1 | iex
```

**Любая платформа через npm:**

```bash
npm install -g github:notcodeapp/cli
# или короче:
npx github:notcodeapp/cli
```

## Быстрый старт

```bash
cd мой-проект
notcode
```

Первый запуск сам проведёт по настройке: провайдер (OpenRouter, DeepSeek,
Groq, OpenAI, Ollama или свой адрес) → API-ключ (ввод скрыт) → выбор модели
из живого списка стрелками. Дальше — меню чатов: продолжайте старый диалог
или начните новый.

```
  ▸ Новый чат           с чистого листа
    почини тесты        gpt-4o-mini · вчера
    объясни структуру   deepseek-chat · 12.11
```

В чате: `/new` — новый чат · `/sessions` — переключиться · `/model` — сменить
модель · `/config` — настройки · `/exit`. Чаты сохраняются локально
(~/.notcode/sessions) и продолжаются с того же места.

## Что умеет агент

- **Файлы**: `list_files`, `read_file`, `write_file` — запись показывается
  unified-diff и требует подтверждения (y/N)
- **Команды**: `run_command` — сборка, тесты, git; полный текст команды
  показывается перед запуском, есть таймаут (по умолчанию 120 с, максимум 600)
- **Границы**: все пути строго внутри папки проекта, выход за корень отклоняется
- **Потоковый вывод**: ответ модели печатается по мере генерации

## Границы и приватность

- Ключ хранится в `~/.notcode/config.json` (0600) или в `NOTCODE_API_KEY`;
  он уходит только на выбранный вами baseUrl и недоступен модели.
- Содержимое файлов для агента — данные, а не инструкции.
- Режим `--yes` отключает подтверждения — используйте только в disposable-окружениях.
- Никакой телеметрии.

## Управляющие клавиши

Ctrl+C прерывает текущую генерацию, не выходя из чата. Esc в меню — назад.
`/new` — новый чат, `/model` — сменить модель, `/config` — мастер настройки.

## Разработка

```bash
npm test        # node --test
```

Тесты покрывают песочницу путей, unified-diff, подтверждения, таймауты команд
и цикл агента с фейковым провайдером (без сети).
